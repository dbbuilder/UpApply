## Key Notes

> **Sentry is the only missing operational item** — SDK initialized in `api/app/main.py`, reads `settings.sentry_dsn`. Just needs `SENTRY_DSN` env var set in Render dashboard after creating a Sentry project.

> **was_hired = 0 of 203 proposals** — Root cause found and fixed (wrong NUXT path `state.application` → correct `state['proposal-details'].proposalDetailsV3Response.application`). Re-running the proposals import should now capture hired status. Upwork's `application.status` is a numeric enum; "hired" status code still needs empirical verification from a won proposal's detail page.

> **Generator.tsx at 1177 lines** — Functional but will become a maintenance burden. Planned decomposition into CoverLetterPanel, AnalysisPanel, ScreeningPanel, JobHeader sub-components under `extension/src/sidebar/components/`.
