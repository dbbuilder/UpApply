Opportunity – Expert Developer for Azure-based Re-architecture Project

Posted yesterday

Worldwide

Summary

The current system is a .NET application with SQL Server backend, handling API ingestion and processing. The goal is to modernize it by moving ingestion to an Azure-based architecture.

Key Details:

Ingestion: Currently in .NET, to be reimplemented using Azure Data Factory (ADF) pipelines, ADF tasks, Azure Functions, Logic Apps, Databricks Notebooks, ADLS Gen2, Key Vault, and Azure DevOps.

Processing: Primarily in PySpark within Databricks, using Unity Catalog.

Storage: Final processed data will reside in Amazon Redshift.

Complexity: The ingestion layer is the most challenging part — requires handling complex API imports.

Domain Knowledge: Helpful if you understand ad campaign structures in Facebook, LinkedIn, Google Ads, etc.

DevOps: Full CI/CD pipeline in Azure DevOps once complete.
